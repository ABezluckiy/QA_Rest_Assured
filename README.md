Pet Project with Rest Assured API Testing

Этот репозиторий содержит небольшой пет-проект с фокусом на автоматизацию тестирования REST API с помощью Rest Assured.

Обзор проекта

Проект представляет собой простое RESTful приложение и набор автоматизированных тестов, которые покрывают основные эндпоинты. Цель - демонстрировать и практиковать API тестирование с использованием Rest Assured, а также лучшие практики написания надежных и понятных тестов.

Технологии

Java 17

Rest Assured

JUnit 5 

Maven

Jenkins


Структура проекта

/src/test/java        - тесты на Rest Assured API

/src/resources/images - дополнительные материалы для тестов

/pom.xml - конфигурация сборки
